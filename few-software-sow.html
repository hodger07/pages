Budget notes:
  • $120/hr is the agreed rate.
  • AI hours are NOT billed — they represent work AI handles that would otherwise be dev hours. Without AI assistance, total would be ~974 human hours ($116,880 @ $120/hr).
  • AI saves ~22% of total effort across the project.
  • QuickBooks sync (Phase 4) is the single most underestimated task in every software project. 40 hours may grow to 60+ if QB API fights back.
  • Phases overlap intentionally — Phase 2 starts while Phase 1 wraps. Total calendar time: ~40 weeks with one dev.
  • With 2 devs, calendar time compresses to ~24–28 weeks.

Working Agreements

  • All code committed daily to company-owned GitHub repos
  • AI code review on every push
  • Weekly Friday demo (15 min, working software only)
  • Milestone = accepted deliverable (not percentage complete)
  • 2-week late tolerance per milestone, then renegotiate or terminate clean
  • Pay on accepted, tested, reversible deliverables — never on demos alone

Production Safety Controls

  1. Staging-first — no direct prod writes from unverified features.
  2. Feature flags for each phase gate.
  3. Canary rollout by team/market before broad enablement.
  4. Dual-run period with measurable parity thresholds.
  5. Rollback tested before each release, not just documented.
  6. Release checklist requires objective evidence (tests pass, logs clean, reconciliation pass).
  7. No AI layer rollout until core workflow SLOs met for a full stability window.
