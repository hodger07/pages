2. Technical Difficulty: Email Extraction

Difficulty Level: Moderately High. The challenge isn't the AI's reasoning; it's the data messiness of email archives.

  • Thread Deduplication: Emails append previous replies. Feeding raw .mbox files to an LLM wastes tokens and creates hallucinated, repeating timelines. We would need to write a Python script to strip HTML, kill duplicate quotes, and normalize time zones.
  • The Pipeline: We cannot dump 500 emails into one prompt and expect a perfect timeline. We must chunk the emails chronologically, use Qwen3-Coder to extract structured JSON (Date, Rep Name, Promise Made, Resolution Status), and then feed that clean data array to Maverick or Opus to synthesize the final discrepancy timeline.
  • Entity Isolation: The script must be tuned to ignore automated "ticket received" emails and purely extract human-in-the-loop SLA breaches.
